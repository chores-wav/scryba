      GUIA DO SCRYBA

      Tutorial de uso

      Escolha um assunto para ver o passo a passo. Você pode abrir ou recolher todas as seções.

      1. Começando: tela inicial e projetos

      A tela inicial reúne seus projetos. Para começar, clique em + Novo Projeto, escolha o tipo Livro ou RPG, informe os dados solicitados e clique em Criar Projeto.

      Na primeira execução, escolha a pasta de armazenamento quando o Scryba solicitar. O programa cria nela uma pasta para cada projeto.

      Abra um projeto pela opção Abrir Projeto no card. Para alterar seus dados, use o botão de edição; para removê-lo, use excluir e confirme a ação.

      O projeto aberto aparece no topo da sidebar. A opção Início ou o logo retorna à tela inicial.

      2. Navegação e configurações

      Use a sidebar para alternar entre Editor, Anotações, Planejador, Personagens, Mundo & Magias, Mural de Estética, Mapa Mental e as ferramentas de organização. O Pad de Áudio aparece em projetos RPG.

      Clique na seta do cabeçalho da sidebar para recolhê-la ou expandi-la. Os ícones continuam disponíveis quando ela está recolhida.

      Abra Configurações pela engrenagem. Lá você pode escolher o tema, fonte do editor, pasta de armazenamento e se a sidebar inicia recolhida. A troca de tema atualiza a aparência das telas.

      3. Escrever e organizar capítulos

      No Editor de Escrita, escolha um capítulo na lista lateral ou clique em + Novo. Edite o título e escreva na área central. Arraste uma imagem do computador para o texto para inseri-la.

      Arraste os capítulos pela lista para mudar a ordem. Clique no selo de status para alternar entre Rascunho, Em Revisão e Finalizado.

      O botão flutuante de três linhas abre as ferramentas de formatação. Selecione o trecho desejado e aplique negrito, itálico, sublinhado, títulos, listas e outras opções do painel.

      O status no rodapé informa quando as alterações foram salvas. Use Ctrl + S para salvar rapidamente. O botão Histórico permite consultar e restaurar versões anteriores.

      Para exportar, use os controles de exportação do editor e escolha o formato disponível, como Word ou PDF.

      4. Anotações e planejamento

      Anotações Rápidas serve para ideias e lembretes separados do texto dos capítulos. Crie uma nota, dê um título e escreva seu conteúdo; selecione uma nota na lista para continuar editando.

      No Planejador, defina metas e organize atos e capítulos planejados. O progresso de palavras usa o texto escrito no Editor; o planejamento permanece separado do manuscrito.

      5. Personagens e fichas

      Na tela Personagens, clique em + Novo Personagem. Preencha nome, papel e resumo, escolha o tipo de ficha/sistema quando aplicável e adicione um retrato pelo seletor ou arrastando uma imagem para a área de retrato.

      Abra um card para ler a ficha. Use Editar para alterar seus dados. No menu do card há ações de organização, como copiar, duplicar ou excluir.

      Os campos da ficha variam conforme o sistema selecionado. Salve as alterações para atualizar a galeria do projeto.

      6. Mundo, tópicos e magias

      Em Mundo & Magias, use as abas para alternar entre os tópicos de worldbuilding e o grimório. Crie tópicos para registrar lugares, grupos, eventos e outras informações do cenário.

      No grimório, crie uma magia e preencha os dados relevantes, incluindo tempo de conjuração, alcance, componentes, duração, efeito e lore. Clique no card para ver os detalhes; use editar ou excluir para mantê-lo atualizado.

      7. Mural de Estética

      Use + Adicionar imagem ou arraste imagens do computador para o mural. Arraste um item para posicioná-lo e use as alças para redimensionar.

      O alinhamento magnético ajuda a alinhar itens ao mover e redimensionar. Os controles no rodapé aproximam, afastam e centralizam a visualização. Arraste o fundo para navegar pelo mural e use a rodinha do mouse para ajustar o zoom.

      8. Mapa Mental

      Clique em + Novo cartão para criar um item. Mova e redimensione cartões para organizar as relações do cenário; o alinhamento magnético ajuda a posicioná-los.

      Ative Conectar e selecione os cartões para criar linhas. As conexões podem se prender às laterais, ao topo ou à base dos cartões. Use o zoom e Enquadrar para navegar pelo mapa.

      9. Pad de Áudio e dados de RPG

      Abra Pad de Áudio pela sidebar. Na área Músicas, adicione arquivos para tocar a faixa escolhida em loop. Em Efeitos sonoros, toque sons sob demanda; efeitos diferentes podem se sobrepor.

      Você pode usar + Adicionar ou arrastar arquivos e pastas para cada painel. O Scryba percorre as pastas e importa somente arquivos de áudio compatíveis; os arquivos aparecem na lista sem a estrutura de pastas. O volume geral fica no topo da tela.

      O botão flutuante de dados fica disponível em projetos RPG fora da tela inicial. Clique nos dados para selecionar quantidades, use Limpar para zerar a seleção e Rolar para ver o resultado. As duas rolagens mais recentes ficam no painel; após a terceira, aparece o histórico completo com os dados e resultados.

      10. Árvore genealógica e linha do tempo

      Em Árvore Genealógica, crie uma árvore e adicione pessoas para organizar relações e gerações. Abra uma árvore da galeria para editar sua estrutura.

      Na Linha do Tempo, adicione acontecimentos com seus dados e ordene-os cronologicamente para acompanhar a sequência da narrativa ou campanha.

      11. Salvamento, versões e dicas rápidas

      O Scryba salva as mudanças do projeto e mostra no rodapé do Editor o horário do último salvamento. Ctrl + S solicita um salvamento rápido de qualquer tela.

      Use Histórico no Editor para recuperar uma versão anterior se precisar desfazer mudanças mais antigas. Ao restaurar, confira o conteúdo recuperado antes de continuar.

      No texto do Editor, Ctrl + B aplica negrito, Ctrl + I itálico e Ctrl + U sublinhado. Os mesmos atalhos funcionam com ⌘ no macOS.

      Se não encontrar uma ferramenta, confira primeiro o projeto aberto e a tela atual. Recursos de RPG, como dados e Pad de Áudio, ficam disponíveis em projetos RPG.
